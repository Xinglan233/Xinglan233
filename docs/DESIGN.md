# 设计说明 · Xinglan233

## 一个整体，而不是卡片拼贴

页面从个人介绍到实际项目，再到统一统计，最后自然接 GitHub 原生项目与贡献区域。README 不尝试用 CSS/JS 重写 GitHub 整站。

头像和原生侧栏保留。正文只写已经确认的身份和公开项目，避免“全栈专家”“用技术改变世界”等空泛人设。

## 视觉规则

- 文字优先：简介与项目使用原生 Markdown，链接可点击，文字可复制。
- 单一面板：活动数字、评级圆环、语言分布共享一个背景、同一字体体系和同一留白节奏。
- 轻主题：白色页面、灰白面板 #F6F7F9、正文 #1D1D1F、次要文字 #62666D。
- 深主题：深色页面、石墨面板 #161B22、正文 #F0F3F6、次要文字 #A4ACB7。
- 蓝色是唯一装饰性强调色；语言用有序低饱和蓝灰，不使用彩虹技术徽章。
- 面板圆角 18，分隔线 1；无大面积渐变、霓虹、毛玻璃、阴影堆叠。
- 桌面 800×332，手机 400×468，不直接把桌面左右两栏无限缩小。
- 系统字体栈，不分发 Apple 字体文件；设备最终显示的字体可能不同。
- 只保留原生绿色贡献图，不重复画第二张日历，也不把图改成贪吃蛇。

## 范围边界

本地 HTML 预览只是便于检查 Markdown 与实际 SVG 的近似渲染，不是 GitHub 官方页面截图。GitHub 原生项目卡片、贡献日历和外层布局无法由个人 README 统一重绘；保留这些原生区是有意的设计取舍。

真实账户统计必须来自授权工作流。本包首次同步前显示空状态，不能将测试数字当成真实履历。
